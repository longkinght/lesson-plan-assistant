# 标准教案结构（内置默认模板）

> 用户未提供学校模板/历史教案时，使用本标准结构生成教案 docx。用户提供模板后，由模板标签映射覆盖本结构（见下节）。

## 标准教案字段与对应标签

| 教案区块 | 内容来源（lesson.json 字段） |
|----------|------------------------------|
| 课程名称 / 授课课题 / 周次 / 学时 / 授课班级 / 授课教师 / 授课日期 / 课型 | lesson_meta.* |
| 教学目标（知识/能力/素质） | objectives.* |
| 学情分析 | student_analysis |
| 教学重点 | key_points[]（逗号连接） |
| 教学难点 | difficult_points[] |
| 教学方法 | methods[] |
| 教学资源 | resources[] |
| 教学过程：课前 | flow.pre_class（四维） |
| 教学过程：课中五环节 | flow.in_class[]（每环节四维） |
| 教学过程：课后 | flow.post_class（四维） |
| 教学反思 | reflection（效果+诊断+改进） |

## 文档格式（python-docx 生成）

- 页面：A4，常规页边距
- 标题：第X周教案（黑体 16pt 居中）
- 一级标题：黑体 14pt；正文：宋体 12pt（小四）
- 基本信息表：8 行 × 4 列表格（字段名+值）
- 教学过程：每个环节一个 4 列子表（教学内容/学生活动/教师活动/设计意图）
- 反思：效果 / 诊断：… / 改进：… 三段式

## 用户模板适配（未来接入）

当用户提供学校模板 docx 时：
1. 扫描模板表格，用标签关键词匹配建立 字段→单元格 映射（如"课程名称"→ (表1,行2,列3)）
2. 从 lesson.json 取对应字段值填充
3. 模板中已预填的有效值（非占位符）优先级：用户输入 > 模板预填 > 默认值
4. 保持模板表格/字体/页眉页脚/布局不变

> 适配脚本将随用户提供真实模板后补充；当前版本以内置标准结构交付。
