# 标准教案版式（内置默认）

> 未提供学校模板时使用。生成器负责统一版式，内容只来自 `lesson.json`。

## 文档结构

| 区块 | 内容来源 | 版式 |
|---|---|---|
| 封面信息 | `lesson_meta.*` | 课程色标题、副标题、金色分隔线、四列信息表 |
| 01 教学目标 | `objectives.*` | 知识 / 能力 / 素质分组，编号目标，绑定知识点用灰色附注 |
| 02 学情与重难点 | `student_analysis`、`key_points`、`difficult_points` | 段落 + 双行表格 |
| 03 方法与资源 | `methods`、`resources` | 双行表格 |
| 04 教学过程 | `flow.pre_class`、`in_class`、`post_class` | 每环节一张四列表：教学内容 / 学生活动 / 教师活动 / 设计意图 |
| 05 教学反思 | `reflection` | 真实性提示 + 效果 / 诊断 / 改进 |
| 附录 | `knowledge_tree` | 知识结构缩进索引，便于核对，可按学校要求删除 |

## 页面与文字规范

- A4，左右 21 mm，上下约 20 mm；
- 页眉：`LESSON PLAN / 课程名称`，细分隔线；
- 页脚：AI 辅助声明 + 页码；
- 正文：宋体 9.2–10.5 pt，行距 1.32–1.4；
- 标题：微软雅黑，深青色；章节编号使用金色；
- 表头深青底白字，正文墨色，边框浅灰绿；
- 表格行禁止跨页拆分，表头跨页重复；
- 内容为空时显示短占位，不伪造教学事实。

## 兼容与边界

- 支持 `.docx` 的软件均可打开；字体缺失时自动回退；
- 标准版式不试图复刻任何特定学校模板；
- 学校有固定表格时，应提供自定义章节风格或在生成后套用学校模板；
- 页数随知识节点数量变化，附录可以先删除再提交；
- 生成器不写入学校 Logo、教师签名、盖章等资产。

## 建议的教师复核

1. 核对课程名称、班级、教师、日期；
2. 核对教学目标的课程规范表述；
3. 核对重点难点与学生实际水平；
4. 核对课中时长与实际铃声安排；
5. 删除附录或把附录另存为课程资产；
6. 上课后补写真实反思与证据。
