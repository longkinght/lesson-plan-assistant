# 教学结构化抽取规则 v2

> 用途：把“周次 + 课题 + 要点”或教材、课标、PPT 文本整理成符合 `lesson-json-schema.md` 的 `lesson.json`。先完成教学结构化，再运行脚本；不要手写 DOCX 或 HTML。

## 主 Prompt

```text
你是一名课程设计师，任务是为一节课建立可执行、可校验的教学结构。
输出一份符合 lesson.json v2.0 契约的 JSON 对象，不要输出 JSON 之外的文字。

输入：
- 周次/学时：{week_hours}
- 课题：{topic}
- 要点：{key_points}
- 教学对象：{learners}
- 补充材料：{source_text}
- 每学时分钟数：{minutes_per_hour}（默认 45）

必须遵守：
1. 只使用输入与补充材料能够支持的事实；无依据时写“待补教材出处”，不得编造教材章节、课标条目或研究结论。
2. 每个知识点都写可观察、可验收的 objective，禁止“了解、熟悉、掌握”作为唯一行为动词。
3. 每条三维目标使用 {text, knowledge_refs}，knowledge_refs 必须指向真实知识点。
4. knowledge_tree 深度优先排列；每个知识点必须有 category、cognitive、objective；分类节点三项留空。
5. flow.in_class 默认五环节：intro、instruction、instruction、practice、summary；每个环节四维齐全。
6. 每个环节 duration_minutes 为正数，合计必须等于 hours × minutes_per_hour。
7. 教案尚未实施：reflection.status 使用 pre_class，三段均以“待课后填写：”开头，不写任何正确率、达成率或预期数据。
8. 不把教材目录照抄成树；每个节点通过“有依据吗、可教可评吗、学生真的需要学吗”三问。
9. 教学难点写学生认知误区与卡点，不写“内容较难”。
10. 保证 JSON 可解析：双引号、无注释、无尾逗号。
```

## 输入收集

开始生成前，至少确认课题、周次和学时。教学对象和要点缺失时，可以做最低限度推断，但必须明确告诉用户推断了什么。教材、课标或旧教案存在时，优先以其为依据。

## 知识点层级

| 层级 | 作用 | 筛选标准 |
|---|---|---|
| L1 | 课程/课题根节点 | 名称与课题一致 |
| L2 | 模块或主题单元 | 能在课堂时间中定位 |
| L3 | 章节或知识簇 | 组织同类知识 |
| L4+ | 可教学知识点 | 有目标、有活动、可评价 |

避免为了凑层级把所有内容都做成知识点，也避免只做两层、无法开展课堂活动。

## 目标写法

不合格：

- “了解栈”
- “熟悉 AI 工具”
- “掌握循环队列”

合格：

- “能够说出栈后进先出的特性，并用一个生活实例解释”
- “能够比较顺序栈与链栈的扩容方式与时间复杂度”
- “能够实现循环队列的入队、出队与队空队满判断”

## 课堂时长

先计算课堂总分钟数，再分给五环节：

```text
总分钟 = lesson_meta.hours × lesson_meta.minutes_per_hour
```

例如 2 学时 × 45 分钟 = 90 分钟，可以是：

| 环节 | 分钟 |
|---|---:|
| 导入 | 5 |
| 新授一 | 25 |
| 新授二 | 25 |
| 互动练习 | 25 |
| 小结与作业 | 10 |

合计必须精确等于 90。企业工作坊或跨天培训可使用小数分钟并设置 `structure: "custom"`，但仍需满足总时长公式。

## 反思真实性

备课阶段只写记录项，不写结果：

```json
{
  "status": "pre_class",
  "effect": "待课后填写：记录课堂练习结果与目标达成情况",
  "diagnosis": "待课后填写：记录学生实际误解与环节执行情况",
  "improvement": "待课后填写：依据课堂记录确定下一轮改进",
  "evidence": ""
}
```

课后如果有真实记录，再将 `status` 改为 `post_class`，填写来源 `evidence`。不得把示例中的百分比或作品数量复制到新课程。

## 生成后的固定流程

```bash
# 1. 契约与质量校验
python scripts/verify_consistency.py --json lesson.json

# 2. 生成三件套
python scripts/lesson_assistant.py --json lesson.json --output-dir output

# 3. 独立回读验收
python scripts/audit_artifacts.py --json lesson.json --output-dir output
```

出现错误时按字段路径修正 JSON，不改脚本绕过校验。提醒项逐条判断：属于课程真实设计的保留，属于缺口或推断的补充或删除。

## 禁止行为

| 错误 | 处理 |
|---|---|
| 编造教材章节、课标条目、课堂数据 | 标“待补”或删除 |
| 只写“讲知识点一/二” | 补活动、教师行为与设计意图 |
| 知识树照抄目录 | 按学生可学、可评重新筛选 |
| 目标无法观察 | 改为行为动词 + 结果 |
| 课中时长与学时冲突 | 重分配，保持总分钟一致 |
| 为了让校验通过而删掉必要字段 | 修内容，不修契约 |
