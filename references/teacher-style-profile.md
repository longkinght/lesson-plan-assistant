# 教师风格档案（Teacher Style Profile）

> 从用户历史教案《人工智能生成艺术教案》与《教学实施计划》提炼。当用户提供学校模板 / 历史教案后，本 Skill 由 "内置标准结构" 切换到 "风格档案驱动" 渲染。
> 机器可读版本：
>
> `teacher-style.json`
>
> （渲染器读取）。

## 风格特征总览

这份历史教案是**章节制大学教案**（不是课时制），字段与标准结构不同，但语义可映射：



| 教师模板字段  | 对应 lesson.json                  | 说明                             |
| ------- | ------------------------------- | ------------------------------ |
| 课时      | lesson\_meta.hours              | 本章总课时（3/6/9）                   |
| 教学方法    | methods                         | 勾选式：■讲授法 □讨论法 ■案例教学 □参与式教学 ■其他 |
| 教学目的及要求 | objectives                      | "目的：… 要求：…" 两段式                |
| 教学环境    | resources \[0] 或默认              | 常用 "多媒体机房"                     |
| 重点 / 难点 | key\_points / difficult\_points | "重点：… 难点：…"                    |
| 讲授内容    | flow.in\_class                  | 重组为 "第一节 / 第二节 / 第三节…"，节内编号列表  |
| 思考题和作业  | flow.post\_class.content        | 每个环节一条作业或综合作业                  |
| 参考文献    | （lesson.json 可加 references 字段）  | 原模板多数留空                        |

## 文档结构（渲染顺序）



```
封面：课程名称教案 + 学期 + 学院/教研室/班级/学分/学时/周学时/任课教师

&#x20; 第1章 章标题

&#x20;   课时 / 教学方法 / 教学目的及要求 / 教学环境 / 重点 / 难点

&#x20;   讲授内容（第一节…第二节…，节内 1. 2. 3. 编号）

&#x20;   思考题和作业 / 参考文献

&#x20; 第2章 …（同上）

教学反思（附加节，原模板无此节，保留作为改进）
```

## 语言习惯（来自原文示例）



* 目的用 "掌握 / 理解 / 了解 / 学会" 开头，如："目的：掌握国内主流在线 AI 绘画平台…"

* 要求用 "学生应能 / 能够 / 熟练运用" 开头："要求：熟练使用即梦等工具完成图像创作…"

* 重点并列用 "，" 与 "、" 分隔；难点以 "如何 / 理解… 的…/ 从… 转向…" 句式为主

* 讲授内容分节标题统一 "第一节 XXX / 第二节 XXX"；节内用 "1. 2. 3." 编号

## 教学实施计划（学期粒度表格）

另一份文档为 "教学实施计划"：周次 × 章节 × 课时 × 内容 × 目的要求 × 重点难点 × 教学环节运用 × 备注 的学期总表。



* 属于**学期粒度**资产（10 章 × 10 周），由多份 lesson.json（每章一份）汇总生成

* 当前渲染器尚未实现学期汇总表；提供多章 lesson.json 后可扩展 `build_lesson_plan.py`

## 使用方式



```
\# 按教师风格生成教案（--style teacher-zhang）

python scripts/build\_lesson\_docx.py --json lesson.json --output 第X章\_教案.docx --style teacher-zhang

\# 主入口同样支持

python scripts/lesson\_assistant.py --json lesson.json --output-dir 输出目录 --style teacher-zhang
```
