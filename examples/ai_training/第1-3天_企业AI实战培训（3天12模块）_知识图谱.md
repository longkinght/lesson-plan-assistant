# 第1-3天 · 企业AI实战培训（3天12模块）

> **课程**：企业AI应用实战训练营  |  **学时**：16.5  |  **知识节点**：16  |  **数据契约**：v2.0

## 1. 知识树

- **企业AI实战培训**
  - **DAY1 AI通识与人机协作**
    - **模块01-02 认知奠基与五步法**
      - **AI能力边界与误区** ` 理解 / 概念性 / 重点 ` — 能够说出AI能做什么/不能做什么，并列举至少3个常见认知误区
      - **保密红线与合规意识** ` 记忆 / 概念性 / 重点 ` — 能够复述保密红线条款，并判断3个涉密场景中哪些数据不可直接投喂AI
      - **人机协作五步法** ` 应用 / 程序性 / 重点;难点 ` — 能够运用'目标定义→素材输入→约束说明→分步执行→验收优化'五步法完成一次岗位任务拆解练习
    - **模块03-04 Agent与AIGC**
      - **Agent与知识库构建** ` 应用 / 程序性 / 重点 ` — 能够把岗位资料切分喂料，构建一个含知识库的最小可行智能体
      - **岗位任务转智能体** ` 创造 / 程序性 / 难点 ` — 能够从调研问卷的岗位高频任务出发，设计并交付一个本岗位最小可行智能体
      - **新媒体AIGC应用** ` 应用 / 程序性 / 重点 ` — 能够使用AI完成生图、生视频、生音乐各至少1例，合成一个AIGC素材包
  - **DAY2 智能体与业务攻坚**
    - **模块05-06 Skill与多Agent**
      - **Skill概念与价值** ` 理解 / 概念性 / 重点 ` — 能够解释Skill与普通提示词的区别，并说出Skill在企业复利中的价值
      - **Skill输入处理输出设计** ` 应用 / 程序性 / 难点 ` — 能够为自建Skill明确输入字段、处理逻辑与输出格式，并通过测试用例验证
      - **多Agent协作流程** ` 分析 / 程序性 / 难点 ` — 能够把一个跨部门任务拆解为多Agent分工协作流程，并绘制协作流程图
      - **专家团机制** ` 理解 / 概念性 ` — 能够说出专家团机制的原理，并举例说明其用于方案评审的场景
    - **模块07-08 痛点攻坚**
      - **数据统计与批量核对方案** ` 应用 / 程序性 / 重点 ` — 能够演示agent解决数据统计与批量核对的完整链路，并分组仿做出一份方案原型
      - **工作总结与汇报材料方案** ` 应用 / 程序性 / 重点 ` — 能够搭建AI撰写工作总结与汇报材料的方案，并在分组实战中产出1份材料
  - **DAY3 Vibe Coding与作品落地**
    - **模块09-10 工作台与实战**
      - **VibeCoding自然语言开发** ` 应用 / 程序性 / 重点;难点 ` — 能够用自然语言向AI描述需求，生成排程计算器、记录台账或数据看板等原型
      - **工作台与小工具原型** ` 创造 / 程序性 / 难点 ` — 能够把一类重复工作封装为可复用的小工具/工作台原型并演示
      - **作品三选一实战** ` 创造 / 元认知 / 重点 ` — 能够三选一（Agent工作流/组合型AI产品/Vibe Coding作品集网站）产出1件可演示作品
    - **模块11-12 展示与复盘**
      - **成果展示与点评复盘** ` 评价 / 元认知 ` — 能够按评分标准演示作品，接受讲师点评与学员互评，并制定30天行动计划

## 6. 术语表

| 术语 | 定义 |
|---|---|
| AI Agent（智能体） | 能自主完成'感知-决策-执行'闭环的AI应用，可处理多步骤任务 |
| 知识库 | 把岗位资料切分后喂给AI，供其检索回答或生成的结构化语料库 |
| Skill | 封装'输入-处理-输出'三要素的可复用AI能力单元，越用越值 |
| 人机协作五步法 | 目标定义→素材输入→约束说明→分步执行→验收优化 |
| Vibe Coding | 用自然语言向AI描述需求，由AI生成代码或原型的开发方式 |
| 提示词（Prompt） | 向AI下达任务的自然语言指令，质量决定输出质量 |
| 多Agent协作 | 多个智能体分工协作，完成跨部门、跨环节的复杂任务 |
| 专家团机制 | 让多个AI扮演不同领域专家，共同评审方案或交叉检查风险 |
